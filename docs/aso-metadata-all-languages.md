# App Store Metadata — Complete Package (18 Localizations)
### iOS QR Code App · every field validated against Apple's limits
*Companion to `aso-qr-app-strategy.md`. Generated from a validated single source — all counts checked programmatically: Title ≤30 · Subtitle ≤30 · Keywords ≤100 · Promotional Text ≤170 · Description ≤4000.*

**How to use this file**
1. In App Store Connect, add each localization under *App Information → Localizable Information* and your version's *Platform Version Information*.
2. Paste each field exactly as written. Keyword fields intentionally have no spaces after commas.
3. Promotional Text can be updated any time without app review — use it for seasonal hooks later.
4. The description does not affect App Store search ranking (that's title/subtitle/keywords); it exists to convert visitors — and it must be TRUE. **Before submitting, delete any bullet describing a feature your app does not have** (e.g. link safety check, scan-from-photo, offline mode). False claims hurt conversion, ratings, and can trigger App Review rejections.
5. Titles are brandless by design (see strategy report §3.4). If you adopt a brand name, re-check the title length before submitting.
