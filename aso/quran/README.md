## 1. Why a Quran/Athan app ranks low in these markets (diagnosis)

1. **Not localized into the languages where the biggest Muslim audiences search.** The two
   largest App Store opportunities in this niche are **Indonesia** (the world's largest Muslim
   population) and the **Arabic** storefronts (one Arabic localization covers Saudi Arabia, UAE,
   Egypt, Qatar, Kuwait, and ~15 more storefronts). If your listing is English-only, an
   Indonesian searching *"jadwal sholat"* or an Arab searching *"مواقيت الصلاة"* will **not find
   you**. This is the #1 lever.
2. **Missing the transliteration variants.** This niche is unique: the *same concept* is spelled
   many ways and each is a separate search term. Miss them and you miss the traffic:
   - call to prayer → **athan · adhan · azan · adzan** (Indonesian) · **ezan** (Turkish)
   - prayer → **salah · salat · solat · sholat · namaz** (UK/Urdu/Turkish)
   - direction → **qibla · qiblah · kiblat** (Indonesian)
   - supplication → **dua · doa** (Indonesian) · **adhkar · azkar · dhikr · dzikir**
   - Ramadan → **ramadan · ramadhan** (Indonesian)
   A good listing deliberately spreads these across Title/Subtitle/Keyword field per locale.
3. **New app, no ranking signals yet.** Ratings, installs and retention drive rank. Win the
   **long-tail** first (e.g. *"hijri calendar", "qibla compass", "murottal", "waktu sholat"*)
   while ratings accumulate.
4. **You haven't used the Ramadan wave.** Downloads in this category spike enormously in the
   ~6 weeks around Ramadan. A listing that isn't pre-optimized for it leaves the single biggest
   growth window of the year on the table (see §5).

## 2. The 3 rules this kit follows

- **Only 3 fields are indexed for search:** Title (highest weight), Subtitle, and the hidden
  Keyword field (100 chars). The **description is NOT indexed** on iOS — it's for conversion.
- **Apple auto-combines single words** across those 3 fields, so we use single comma-separated
  words, no spaces, and never repeat a word (a repeat = wasted characters, zero extra weight).
- **Each storefront is indexed independently** — so every locale you add is a fresh
  30 + 30 + 100 characters. The Arabic localization alone unlocks ~20 storefronts at once.

## 7. Apply it (App Store Connect)

1. App Store tab → language dropdown → **+ Add Language**: English (U.K.), **Arabic**,
   **Indonesian**. (English U.S. already exists.)
2. Paste **Name, Subtitle, Promotional Text, Description** + the **Keywords** field per language.
3. Add **localized screenshots** (captions provided in each file). Arabic screenshots are **RTL** —
   mirror the layout.
4. Fill **Terms of Use** + **Privacy Policy** URLs. If you offer an auto-renewable subscription,
   keep the subscription-disclosure block in the description (Apple rejects without it); if the
   app is free, delete that optional block.
5. Submit a new version — title/subtitle/keyword changes only go live when it's approved.

## 8. Beyond metadata (ranking & retention levers specific to this app)

- **Ratings prompt** after a positive moment (e.g. after Athan plays / a Quran session). Top-3
  ranking factor.
- **Widgets + Apple Watch + Lock Screen** prayer-time complications → strong retention and great
  screenshot material.
- **Offline Quran & Qibla** → reliability = better reviews.
- **IAP/subscription display names are indexed** — name them with keywords, e.g.
  `Premium — Quran Audio & Athan`.
- Iterate keywords every ~2–3 weeks using App Store Connect → **Analytics → Search terms**.

## 9. Guardrails (so App Review doesn't reject you)

- **No other app's trademark** in metadata (don't put "Muslim Pro" or "Athan Pro" in your
  keywords). Rejection + takedown risk.
- **Respectful, accurate religious wording** (e.g. "Holy Quran", correct prayer names). Avoid
  overclaiming ("100% accurate" etc.).
- Keyword field: single words, comma-separated, **no spaces**, no repeats.
